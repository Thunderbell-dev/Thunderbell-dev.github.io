## ✨ PurrEngine — The Purrfactory’s All-Purpose Assistant Bot! 🤖

Born from code, powered by cat-like precision, and trained in the art of problem-solving, **PurrEngine** is always on duty to keep things running smoothly. Need help with event planning? Troubleshooting member roles? Organizing family raids? Just meow the word. 🐾

Think of it as your silent operator in the background — quick, responsive, and built to keep your Discord life organized and flowing. From daily tasks to chaotic NosTale emergencies, it computes, it purrs, and it delivers. 😼

### 🧩 Beta Feature Set:

* `/signup` — The star of the system 🌟
  → Custom **event sign-up UI**
  → Automated **notifications & pings**
  → **Alt support**
  → Each event gets its **own thread**
  → Optional **“maybe attending”** status

* `/ping_role` — Ping specific roles directly

* `/translate msg_link:` — Translate any message by link

* `/translate_section` — Translate the last 10 (or a custom number) of messages

* 🌐 React with a **language flag emoji** to auto-translate messages

* `/clear_dm_history` — Clean up your DM thread with the bot

* `/list_members` — View all Discord members in one list
